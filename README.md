# AsoManPesc-SitioWeb

Sitio web de la Asociación de Productores de Mango de Pescadero (AsoManPesc).

- **Frontend:** React + Vite + Tailwind (carpeta `src/`)
- **Backend:** Express + MySQL (carpeta `server/`)

## Cómo ejecutarlo

1. Instala MySQL y prepara la base: sigue **[GUIA_MYSQL.md](GUIA_MYSQL.md)** (pasos 1 a 3).
2. Terminal 1 (servidor): `cd server` → `npm install` → `npm run setup` → `npm start`
3. Terminal 2 (página): `npm install` → `npm run dev` → abre http://localhost:3000
